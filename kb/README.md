# Knowledge Base — 지식 보관소 (비공개 SSOT)

포트폴리오·CV·소개글의 **단일 출처(SSOT)**가 되는 비공개 지식 보관소.
경력·수상·프로젝트·논문 등을 **카테고리 + 항목**으로 관리한다 (추가/수정/삭제).
로컬 웹앱으로 브라우저에서 관리하고, 데이터는 git 친화적 JSON 한 파일에 담긴다.

이 저장소는 [PORTFOLIO-WORKFLOW.md](../PORTFOLIO-WORKFLOW.md)의 **2단계(위키/지식 보관)**에 해당한다.

---

## 실행

```bash
python3 kb/server.py            # http://127.0.0.1:8765 열기
python3 kb/server.py --port 9000
```

브라우저에서 위 주소를 연다. 로컬 전용(127.0.0.1 바인딩), 외부 의존성 없음(파이썬 표준 라이브러리만).
서버가 켜진 동안 편집 내용은 즉시 `kb/data/kb.json`에 저장된다.

## 화면

```
┌ Knowledge Base ─────────────────────────────────────────────┐
│ 사이드바              │ [카테고리명]  N개   [검색]  [+ 항목 추가] │
│  전체        (50)     │ ┌───────────┐ ┌───────────┐            │
│ ▸경력       (4) ✎ ✕  │ │ 제목(KO)   │ │ 제목(KO)   │  ← 항목 카드 │
│  주요 사례   (6)      │ │ Title(EN) │ │ Title(EN) │            │
│  역량       (6)      │ │ 본문 발췌… │ │ 본문 발췌… │            │
│  …                   │ │ #태그 meta │ │ #태그 meta │            │
│ [+ 카테고리]          │ └───────────┘ └───────────┘            │
└──────────────────────┴──────────────────────────────────────┘
   카드 클릭 → 편집 모달 (제목 KO/EN · 본문 KO/EN · 태그 · 메타 key/value)
```

- **카테고리**: 추가(`+ 카테고리`), 이름변경(✎), 삭제(✕, 항목까지 함께), 순서변경(↑)
- **항목**: `+ 항목 추가` 또는 카드 클릭 → 모달에서 제목/본문(EN·KO)·태그·메타 편집, 저장/삭제
- **항목 순서**: 카드 hover 시 ↑ ↓
- **검색**: 상단 검색창 — 제목·본문·태그·메타를 전 카테고리에서 필터
- 좁은 화면에서는 사이드바가 상단 카테고리 칩 바로 접힘
- 단축키: `Esc` 닫기, `⌘/Ctrl + Enter` 저장

## 파일

| 파일 | 역할 |
|------|------|
| `server.py` | 로컬 백엔드 + 앱 서빙 (stdlib `http.server`) |
| `app.html` | 웹앱 프론트엔드 (바닐라 JS, 단일 파일) |
| `seed.py` | `index.html` → `data/kb.json` 초기 시드 |
| `data/kb.json` | **데이터** (카테고리 + 항목). pretty-print JSON, git 추적 |

## 데이터 구조

```json
{
  "categories": [{ "id": "cat_x", "name": "경력 (Career)", "order": 0 }],
  "items": [{
    "id": "itm_x", "category": "cat_x", "order": 0,
    "title": "…(KO)", "title_en": "…(EN)",
    "body": "…(KO)", "body_en": "…(EN)",
    "tags": ["…"], "meta": { "org": "…", "year": "…" },
    "updated": "2026-07-07 05:40"
  }]
}
```

`title`/`body`는 한국어, `title_en`/`body_en`은 영어. `meta`는 자유 key/value(연도·기관·지표·링크 등).
이중언어로 저장하므로 이후 포트폴리오(EN/KO)와 CV 어느 쪽으로도 파생할 수 있다.

## 초기 시드

```bash
python3 kb/seed.py            # data/kb.json 없을 때만 생성
python3 kb/seed.py --force    # 덮어쓰기(주의: 앱에서 편집한 내용 사라짐)
```

기존 `index.html`에서 9개 카테고리 / 50개 항목을 파싱해 넣는다:
경력·주요 사례·역량·AX 도구·수상·학력/자격·논문/강연·철학/노트·소개.
(갤러리 사진 캡션과 제품 커버리지 표는 시드에서 제외 — 필요하면 앱에서 카테고리를 만들어 추가)

> ⚠️ 시드는 최초 1회. 이후에는 앱에서 편집하며, `--force` 재시드는 앱 편집분을 덮어쓴다.
```
